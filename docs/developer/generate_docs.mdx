To generate a preview copy of the docs:

1. Commit and push your work to the Megatron repository.
2. Wait for CI checks to complete on your PR.
3. Review the content built for you at the preview link associated with your PR.



To generate docs locally:

1. Review the [Fern Quick Start](https://buildwithfern.com/learn/docs/getting-started/quickstart).
2. Install the Fern CLI. For example:
   ```bash
   npm install -g fern-api
   ```
3. From the `docs/fern` directory, run `fern docs dev`. For example:
   ```bash
   fern docs dev
   ```
